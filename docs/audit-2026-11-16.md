## Opravené chyby

| Oblast | Zjištění a výsledné chování |
| --- | --- |
| Aktivity | Firestore datum poslané z editace jako JSON se správně zpracuje. Přidané fotografie se skutečně uloží a ověří se vlastnictví i limit šesti obrázků. |
| Moje aktivity | Další stránky načítají pouze záznamy přihlášeného uživatele. Po smazání zmizí záznam i z lokálního seznamu; seznam fotek odpovídá výsledku mazání. |
| Týmové součty | Editace stejného typu přičítala celou novou vzdálenost a navyšovala počet aktivit. Nový přepočet zapisuje rozdíl proti předchozímu příspěvku, zvládá souběžné editace i opakování po částečném selhání. |
| Uložení | Opakování stejného požadavku při výpadku odpovědi nevytvoří druhou aktivitu. Identifikátor je vázaný na konkrétního uživatele a rozepsaný formulář. |
| Mazání | Aktivita se před úklidem označí jako mazaná. Týmový příspěvek se odečte právě jednou, editace mazané aktivity není povolená. |
| Fotografie | Mazání používá zachycenou URL fotografie; souběžná změna pořadí nemůže odstranit jinou fotografii. |
| Přezdívky | Současná změna přezdívky a avataru nevrátí staré údaje do veřejného profilu. Výsledky a účastníci používají aktuální přezdívku. |
| Motivy | Server akceptuje světlý motiv. Pouhé načtení již nezmění čas cache a neblokuje novější nastavení z jiného zařízení. Opožděná odpověď počasí nepřepíše ruční volbu motivu. |
| Načítání | Sdílené dotazy čekají na přihlášení a oddělují cache podle účtu. Účastníci rovněž čekají na dokončení přihlášení. |
| Trasy | Ověření administrátora již nevyhazuje běžného uživatele ze čtení doporučených tras. |
| GPX | Import i proxy mají shodný limit 15 MB. Výpočet vzdálenosti zvládá namespace, obrácené pořadí atributů a oddělené segmenty. Neplatné souřadnice se nepoužijí. Proxy hlídá skutečnou velikost i cíle přesměrování. |
| Počasí | Kódy dešťových přeháněk 80–82 se neoznačují za sníh. Časy předpovědi se převádějí z absolutního Unix času a nezávisí na časové zóně serveru. |
| GPS | Ukončení během pauzy neodečítá pauzu dvakrát. Ignorují se starší GPS body a dlouhý výpadek nezablokuje všechny další body. Uvolněný wake lock se dá získat znovu; neúspěšné získávání první polohy se ukončí. |
| Trenér | API odmítne neexistující datum a měsíc. Souběžné ukládání různých měsíců nepřepíše jiný plán. Během ukládání se nepřepíná měsíc ani druh aktivity. |
| Upozornění | Platný čas celé hodiny se uloží místo tichého nahrazení výchozím časem. Dnešní a zítřejší připomínka mají oddělené značky doručení. |
| Zvonek | Zobrazuje posledních 50 upozornění podle data, počítá všechny nepřečtené a hromadné označení bezpečně zpracuje i více než 500 položek. Neúspěšné označení se nezobrazí jako úspěšné. |
| Komentáře | Souběžné smazání téhož komentáře nesníží počet dvakrát. Selhání upozornění neohlásí již uložený komentář nebo lajk jako neuložený. |
| Účty | Úklid nepoužívá collection-group indexy a odstraní také vnořená push předplatná. Účet v průběhu mazání nemůže přidávat nové aktivity, úklid lze opakovat. Chybová zpráva nepředstírá, že se nic nezměnilo. |
| Oprávnění | Server ověřuje zrušení přihlašovacích tokenů. Zápisové endpointy aktivit odmítají ID obsahující cestu. Ukládají se pouze push adresy známých poskytovatelů; ověřování registračního kódu má limit pokusů. |
| Další | Formátování času již neukazuje 1:60. Denní filtry zahrnují celý místní den. |

## Ověření

- `npm test`: regresní scénáře nad skutečnými funkcemi, API a komponentami s náhradami pro prohlížeč a databázi. Test Firestore pravidel se bez emulátoru záměrně přeskočí.
- `npm run test:emulator`: izolované databáze v opravdovém Firestore emulátoru; testují skutečné transakce, souběh, oprávnění, editace a mazání aktivit, media, profily, plány, upozornění nad 500 položek a úklid účtu.
- `npm run typecheck`, `npm run lint`, `npm run build` a `git diff --check`.

Zbylá upozornění ESLintu nejsou zaměňována za prokázané funkční chyby. Testy používají izolované zkušební účty; nedochází k vytváření záznamů ani mazání skutečných uživatelů v produkci. Cloudinary a odesílání push zpráv se v integračních testech nahrazují.

Neproběhl úplný ruční průchod pod skutečným účtem, skutečný pohyb s telefonem, test klávesnice Android/iOS ani skutečné doručení push zprávy na zařízení. Automatické ověření za tyto testy nevydáváme. Produkční pravidla Firebase se tímto vydáním nemění.
